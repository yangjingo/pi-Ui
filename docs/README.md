## 维护入口

项目根目录的 [`AGENTS.md`](../AGENTS.md) 规定了 AIDA UI 的实现边界与代理工作流。所有 React UI、CANVAS 布局、图标或动效改动必须先读取项目内的 TASTE 与 Amicro 技能，并以 DSH 原生设计系统和 [AIDA UI 设计语言](./design-language.md) 为最终约束。
