# AIDA Release Demo

This sanitized workspace is used to capture public product screenshots for the
AIDA slide deck. It contains no user data, credentials, or machine-specific
paths.

## Demo surfaces

- Files: inspect the small project tree.
- Trajectory: verify the native DSH view is mounted inside Canvas.
- Canvas: render this Markdown document in place.
- Pet: keep `healing-whale-hit` visible without covering persistent controls.

## Release principle

The demo proves plugin composition while keeping DSH sessions, workspaces, and
the Pet runtime independently removable.
