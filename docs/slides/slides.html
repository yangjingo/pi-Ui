08 / INSTALLCORDIS PLUGIN

1 个命令，AIDA 进入 DSH

开发时链接本地目录，交付时安装归档包。两条路径共享同一个 Cordis 插件条目。

LOCAL CHECKOUT01

开发与集成

在 DSH 仓库中加入本地插件目录，然后启动 Web profile。

pnpm dsh plugin --profile web add \
  ./packages/client/ui-aida

pnpm exec tsx apps/cli/src/bin.ts \
  web --no-open
BUILT ARCHIVE02

归档与分发

安装构建后的 tarball。移除插件不会删除现有会话与项目数据。

dsh plugin --profile web add \
  ./deepseek-ai-dsh-client-ui-aida.tgz

dsh plugin --profile web remove \
  @aida/aida-ui-dsh
单一插件条目设置页中以 ui-aida 独立管理
安装后即时生效品牌、CANVAS 与内网模型入口一起装配
移除保持数据会话、项目文件与已存模型配置不被删除
