09 / INSTALLCORDIS PLUGIN + PET PACK

1 条安装链，AIDA 与鲸鲸进入 DSH

开发时链接本地目录并同步宠物包，交付时由 profile 命令安装。插件与素材保持独立、可移除。

LOCAL CHECKOUT01

开发与集成

在 DSH 仓库中加入本地插件目录，然后启动 Web profile。

pnpm dsh plugin --profile web add \
  ./packages/client/ui-aida

pnpm exec tsx apps/cli/src/bin.ts \
  web --no-open

node ./packages/client/ui-aida/scripts/install-whale.mjs
BUILT ARCHIVE02

归档与分发

安装构建后的 tarball。移除插件不会删除现有会话与项目数据。

dsh plugin --profile web add \
  ./aida-aida-ui-dsh-0.1.0-rc.11.tgz

dsh plugin --profile web remove \
  @aida/aida-ui-dsh

pnpm --dir <DSH_HOME>/profiles/web \
  exec aida-install-whale
单一插件条目设置页中以 ui-aida 独立管理
安装后即时生效品牌、CANVAS、模型入口与鲸鲸一起装配
移除保持数据会话、项目文件与已存模型配置不被删除
