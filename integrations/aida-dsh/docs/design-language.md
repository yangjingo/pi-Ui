# AIDA UI 设计语言

本文定义 AIDA UI 插件在 DSH Web 中的视觉与交互基线。目标不是建立一套脱离 DSH 的新组件库，而是在不改变 DSH 行为模型的前提下，为交付导航、CANVAS 和品牌表面提供一致、克制、可逆的体验。

## 1. 设计定位

- `产品类型`：面向高频操作用户的开发者工具与交付态势导航仓。
- `视觉方向`：紧凑、清晰、安静，优先信息层级与操作效率。
- `系统关系`：DSH 原生设计系统优先，AIDA 负责品牌层、CANVAS 编排与必要的状态过渡。
- `默认参数`：`DESIGN_VARIANCE 3`、`MOTION_INTENSITY 2`、`VISUAL_DENSITY 6`。
- `主题策略`：消费语义化 `--dsw-*` token，跟随 DSH 的 light、dark 与 system 设置，不建立平行色板。

## 2. 品牌与文案

- AIDA 品牌组合由 Logo、`AIDA`、`DELIVERY INTELLIGENCE`、文案“你的交付态势导航仓”和“预览版”构成。
- Logo 与字标使用 `assets/` 中的正式资源，不重绘、不改变比例、不添加装饰性滤镜。
- 品牌只强化入口与身份，不抢占会话内容、轨迹记录和文件预览的视觉优先级。
- 产品界面不使用营销页式大标题、渐变堆叠、玻璃卡片或无语义装饰。

## 3. CANVAS 结构

CANVAS 是会话右侧的 details 轨道，默认宽度与会话区域协调，可拖拽并支持最大化。其三个页签遵循同一顶部节奏：

| 项目 | 标准 |
| --- | --- |
| 工具栏高度 | `40px` |
| 工具栏水平内边距 | `8px` |
| 工具栏控件间距 | `6px` |
| 标签字号 | `12px` |
| 图标尺寸 | `14px` |
| 紧凑按钮高度 | `26px` |
| 搜索/导入控件高度 | `28px` |
| 按钮圆角 | `4px` |
| 输入框/分段控件圆角 | `6px` |

### 文件

- 搜索、导入文件与导入文件夹位于同一行，不叠加第二层导入菜单。
- 文件与文件夹操作使用图标加本地化标签，图标不代替必要的语义。
- 文件树保留信息密度，行高、缩进和选中状态服从 DSH 文件表面，不做卡片化包装。

### 轨迹

- 直接复用 DSH `@deepseek-ai/dsh-client-ui-trajectory` 的完整视图，AIDA 只负责入口和容器。
- 回合与调用折叠使用 DSH Chevron primitive，不使用手绘 SVG。
- 会话日志下载位于轨迹视图自身的水平操作行，按钮与相邻图标保持 `14px` 图标和 `26px` 点击区域。
- 工具栏、搜索框和折叠操作与文件、画布工具栏共享尺寸基线。

### 画布预览

- 文件页签、引用、编辑、预览和相关模式控制保持单行、等高、低噪声。
- 引用和编辑操作使用图标加短标签；窄宽度下优先保留图标、可访问名称与 tooltip。
- 预览内容是视觉主体，工具栏不得使用高对比大按钮或持续动画争夺注意力。

## 4. 图标与控件

- 首选 DSH client UI primitives，保持同一套描边、圆角、视口和视觉重量。
- DSH 缺少语义图标时才使用项目现有 Lucide React 图标，并采用与构建器兼容的深层导入。
- 同一工具栏不得混用填充图标、粗描边图标和手绘 SVG。
- 不使用 emoji、文本符号或 CSS 图形替代产品图标。
- 图标按钮必须提供本地化 `aria-label`、`title` 或现有 tooltip。

## 5. 排版、间距与形状

- 继承 DSH 字体和 `--dsw-font-*` 排版 token，不把 Amicro 示例中的 Outfit 字体带入插件。
- 工具栏标签采用 `12px` 基线；标题、正文、辅助信息继续使用 DSH 现有层级。
- 同一层级只使用一套圆角：工具按钮 `4px`，输入与分段容器 `6px`，面板圆角服从 DSH 外壳。
- 优先通过留白、细分隔线和背景层级组织内容，避免把每个区域包装成独立卡片。

## 6. 动效

动效用于解释变化，而不是装饰界面。AIDA 从 Amicro 技能中采用微过渡原则，但不复制其目录卡片、色板、haptics 或 toast 约定。

- `加载`：会话加载使用品牌化但低干扰的循环信号；减少动态效果时停止旋转。
- `页签`：内容切换采用短促淡入或极小位移，避免整个 CANVAS 横向飞入。
- `提示`：CANVAS notice 的出现、更新和退出保持连续，避免瞬间跳变。
- `反馈`：按钮按下可使用轻微缩放或颜色反馈，但工具栏 hover 不产生位置漂移。
- `时长`：常规状态过渡 `160-220ms`；复杂内容不得为了“顺滑”延长等待。
- `缓动`：需要强调收敛时可使用 `[0.16, 1, 0.3, 1]`。
- `性能`：优先 `opacity` 与 `transform`，避免动画化宽高、布局轨道和大面积阴影。
- `无障碍`：所有非必要动效响应 `prefers-reduced-motion: reduce`。

## 7. 国际化

- 可见文字、搜索占位、tooltip、空状态、错误、下载说明和无障碍标签必须进入插件 locale 表。
- 中文和英文 key 同步新增，语言切换后同一页面不得残留另一种语言。
- DSH 的“Workspace”在 AIDA 可见表面统一表达为“项目”/“Project”，底层 API 名称保持不变。
- 不通过 DOM 文本匹配新增业务逻辑；兼容性观察器只用于可逆的现有界面文案接管。

## 8. 设计技能工作流

任何 UI 改动前必须读取：

1. `../.agent/taste-skill/SKILL.md`
2. `../.agent/amicro-design-system/SKILL.md`

执行顺序：先用 TASTE 做现状审计并声明设计参数，再用 Amicro 检查状态过渡、缓动与 reduced-motion，最后按 DSH 原生设计系统收敛实现。技能中的通用示例不能覆盖本文件的产品约束。

## 9. 完成标准

- Files、Trajectory、Canvas preview 的工具栏高度、字号、图标和控件节奏一致。
- 明暗主题下层级清晰，焦点、hover、active、disabled 状态可辨。
- 中文与英文切换完整，无硬编码残留。
- 键盘操作、tooltip、`aria-label` 与 reduced-motion 可用。
- 移除 AIDA 插件后，DSH 原始行为与轨迹入口能够恢复。
